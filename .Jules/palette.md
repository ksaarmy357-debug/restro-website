## 2026-08-12 - Accessible WAI-ARIA Accordion Pattern for Accordion Toggles
**Learning:** Transitioning FAQ or information blocks from div elements to semantic heading and button elements significantly enhances keyboard navigation and screen-reader accessibility. By using `<h3>` with a `<button>` sibling model and attributes (`aria-expanded`, `aria-controls`, `role="region"`, `aria-labelledby`), the content is structured and easily searchable. Direct application of font-family, font-size, and high-contrast `:focus-visible` styles ensures visual elegance is fully preserved without relying on brittle generic focus boundaries.
**Action:** Always replace interactive list-like toggles with semantic native button elements enclosed in semantic headers, and systematically synchronize ARIA boolean attributes (like `aria-expanded` as literal strings) alongside CSS transitions that target both standard icon tags and SVGs generated via Lucide CDNs.
