## 2026-11-04 - Accessible Accordion Pattern with Custom Buttons
**Learning:** In design systems using custom CSS typography and Lucide icon replacement, semantic accordion triggers require nesting a styled `<button>` inside a heading tag (`<h3><button>`). To prevent visual regressions, button resets (`background: transparent`, `border: none`, `color: inherit`, `width: 100%`) and font styles must be explicitly attached to the button, and Lucide's dynamic SVG conversion requires styling both `i` and `svg` for rotate animations.
**Action:** When implementing accordions in similar design systems, use `<h3><button type="button" class="accordion-header" id="f-h-X" aria-expanded="false" aria-controls="f-c-X">...` with `:focus-visible` styling and target both `i` and `svg` for transform states.
