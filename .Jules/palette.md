## 2026-03-31 - Accessible FAQ Accordion Component
**Learning:** Standard interactive elements like accordions should always be built using semantic `<button>` tags within appropriate heading wrappers `<h3>`. When using modern CDN-based icon sets (like Lucide) that dynamically render inline `<svg>` elements on the client-side, CSS transition rules targeting only `i` selectors will fail once icons are replaced. Consolidating the transition definitions on both `i` and `svg` tags (e.g. `.accordion-header i, .accordion-header svg`) ensures styling and rotation animations are flawlessly applied regardless of when or how rendering occurs.
**Action:** Always wrap interactive accordion triggers in semantic headings, ensure `aria-expanded` and `aria-controls` are programmatically synchronized using explicit string values, and declare multi-tag transition rules to handle dynamic inline SVG replacements gracefully.
