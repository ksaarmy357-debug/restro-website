## 2026-03-02 - Accessible Accordion Patterns
**Learning:** For accessible accordions, content areas must have `role="region"` and `aria-labelledby` pointing to the triggering button's ID. Buttons must be wrapped inside standard headings `<h3><button>` rather than having heading tags inside buttons. ARIA attributes must be explicitly updated using string literals 'true' and 'false' instead of raw boolean values to ensure consistent behavior across all screen readers.
**Action:** Always structure accordion items using semantic HTML: `<h3><button aria-expanded="false" aria-controls="content-id">...</button></h3>` followed by `<div id="content-id" role="region" aria-labelledby="button-id">...</div>`. Update ARIA state using string values and ensure correct CSS focus-visible state indicators.
