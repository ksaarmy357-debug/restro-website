## 2026-10-22 - FAQ Accordion Accessibility & Semantic Hierarchy
**Learning:** Replacing non-semantic `div` headers in accordions with `<h3><button>` elements dramatically improves screen reader navigation and keyboard focusability. When converting headings to buttons, heading font properties (`font-family`, `font-size`) must be applied to the button element so visual typography remains unchanged. Additionally, CSS transitions on Lucide icons must target both `i` and `svg` selectors since Lucide converts `<i>` tags into `<svg>` elements upon rendering.
**Action:** Always structure accordions as `<h3><button type="button" aria-expanded="false" aria-controls="...">` with `role="region"` content panels, update `aria-expanded` via JS with string literals `'true'`/`'false'`, and target both `i` and `svg` for icon rotation CSS rules.
