## 2026-07-19 - Accessible and Seamless Accordion Component Pattern
**Learning:** For semantic and standard-conforming web accessibility, accordion headers must use the `<h3><button>...</button></h3>` hierarchy. Placing heading elements inside buttons is invalid HTML. When implementing accordions, interactive headers should not use `aria-haspopup="true"`. Sibling nodes must have their ARIA attributes synchronized via string literals ('true'/'false') on transition to ensure assistive technology receives accurate states.
**Action:** When refactoring interactive sections or accordions in this layout, always replace generic interactive `div` elements with `<button type="button">` wrapped by heading structures. Move heading typography styles directly onto the buttons, apply `:focus-visible` with high-contrast outlines, and synchronise `aria-expanded` and `aria-controls` explicitly inside script controllers.
