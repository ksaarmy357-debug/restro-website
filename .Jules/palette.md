## 2026-06-23 - [Accessible Accordion Pattern]
**Learning:** Converting interactive `div` elements to semantic `button` elements is critical for accessibility. Use `aria-expanded` and `aria-controls` for the trigger, and `role="region"` with `aria-labelledby` for the content area to provide a robust experience for screen reader users.
**Action:** Always check interactive components for semantic HTML and ARIA attributes. Implement `:focus-visible` for clear keyboard navigation cues.
