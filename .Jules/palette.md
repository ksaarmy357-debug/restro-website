## 2026-08-10 - Semantic Accessible Accordions with Button Headers
**Learning:** Placing headings or raw div elements as interactive accordion headers causes accessibility issues because screen readers don't perceive them as controls. Standard buttons styled with CSS (e.g., removing borders, transparent backgrounds, text aligning) are the correct interactive pattern for accordions. When using third-party icon libraries like Lucide, both the `i` and dynamically rendered `svg` elements must be targeted in transition selectors to ensure proper rotation states.
**Action:** Always wrap the header trigger inside a `<button type="button">` element styled to match the surrounding container, apply ARIA attributes (`aria-expanded`, `aria-controls`, `aria-labelledby`, `role="region"`), and target both `i` and `svg` selectors in CSS transition rules.
