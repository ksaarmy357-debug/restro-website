## 2026-03-24 - Accessible Single-Open Accordions
**Learning:** Combining heading structures with native buttons (`<h3><button>`) is the gold standard for accessible accordions, but it requires careful coordination of keyboard navigation focus states, ARIA associations (`aria-expanded`, `aria-controls`, `role="region"`, `aria-labelledby`), and JS attribute synchronization. Additionally, dynamically rendered elements and third-party icon libraries that replace `<i>` tags with `<svg>` tags require consolidated CSS targeting to prevent transition style regressions.
**Action:** When implementing accordions, always wrap headers inside headings, set semantic ARIA properties dynamically, handle transitions on both `i` and `svg` selectors, and maintain high-contrast `:focus-visible` styles with outline-offset to support custom pointer visual indicators.
