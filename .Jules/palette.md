## 2026-07-20 - Accessible Single-Open Accordions
**Learning:** Standard accordion elements often fail semantic HTML and keyboard accessibility, particularly when interactive regions wrap headings or lack ARIA state markers. By using the standard `<h3><button type="button">` pattern combined with `aria-expanded` and `aria-controls` linked to a content `role="region"`, we establish robust assistive technology semantics. Transitioning both CSS `i` and `svg` selectors is critical when third-party libraries (like Lucide) dynamically replace elements.
**Action:** Always structure accordion triggers as `<button type="button">` nested inside hierarchical heading elements, explicitly link them to content regions using `aria-controls` and `aria-labelledby`, and ensure keyboard-visible outlines are clear and not obscured by custom pointer elements.
