## 2026-06-22 - Semantic Accordion Pattern
**Learning:** The correct semantic pattern for accessible accordions is `<h3><button>...</button></h3>`. Placing a heading tag inside a button is invalid HTML as buttons should only contain phrasing content.
**Action:** Always wrap the toggle button in a heading element and ensure the button itself only contains phrasing content (text, icons).
