## 2026-03-01 - Accessible WAI-ARIA Accordion Pattern with Custom Buttons
**Learning:** Wrapping interactive `<button type="button">` elements inside heading tags (`<h3>`) is the correct semantic pattern for accessible accordions. Converting standard header divs to buttons requires resetting native button styles (transparent background, zero border, text-align left, inherit font-family and font-size) while adding high-contrast `:focus-visible` outlines. In a single-open accordion, JavaScript must explicitly set the `aria-expanded` state of all inactive accordion buttons to `"false"` (using string literals) to keep screen readers synchronized and prevent multiple sections from concurrently claiming an open state. Additionally, decorative icons inside buttons must possess `aria-hidden="true"` to avoid redundant or confusing announcements.
**Action:** When implementing or refactoring accordions, always wrap interactive buttons inside semantic heading elements, use high-contrast `:focus-visible` styles with a clear outline-offset for keyboard navigation, and apply rotation transitions on both `i` and compiled `svg` selectors to ensure compatibility with dynamic third-party icon libraries like Lucide.
