## 2026-08-04 - Accessible Accordion Pattern
**Learning:** In a high-end luxury UI, interactive elements like FAQ accordions can lose accessibility when built with generic divs. Converting accordions to use semantic `<h3><button>` structures ensures keyboard focus and screen reader accessibility. By adding proper ARIA attributes (`aria-expanded`, `aria-controls`, `role="region"`, `aria-labelledby`), screen readers can cleanly interpret state transitions. Decorative icons inside buttons should have `aria-hidden="true"`, and transition selectors should target both `i` and `svg` to support dynamic Lucide replacement.
**Action:** Always use semantic buttons for accordion headers with explicit `type="button"`, bind them to content regions using `aria-controls` / `aria-labelledby` with matching IDs, and keep focus states highly visible with high-contrast `:focus-visible` styles.
