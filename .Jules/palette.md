## 2026-11-09 - Accessible Accordions in Luxury Dark Themes
**Learning:** In luxury visual designs with custom blended cursors, replacing non-semantic div headers with `<button>` elements nested inside `<h3>` tags requires migrating heading typography (`font-family: 'Playfair Display'`, `font-size: 1.5rem`) and full-width block alignment onto the button element itself. Moreover, high-contrast `:focus-visible` outlines (`outline: 2px solid var(--accent-amber) !important`) are essential so keyboard focus remains legible against blended cursor artifacts.
**Action:** When converting custom accordion triggers to standard accessible buttons in dark glassmorphism layouts, apply transparent button resets, explicit typography styles, and high-contrast `:focus-visible` styling with synchronized ARIA attributes.
