## 2026-03-24 - Semantic Accessible Accordions with Custom Cursor Interactions
**Learning:** In a design system featuring a custom cursor with mix-blend-mode: difference, standard visual focus indicators can be obscured. Moving heading-specific typography styles from h3 to a nested semantic button ensures interactive region hierarchy remains consistent. Furthermore, ARIA attributes (like aria-expanded) must be updated as explicit strings ('true'/'false') rather than raw booleans, and Lucide/SVG icon selectors must be consolidated to ensure smooth CSS state transitions on element replacement.
**Action:** When implementing accordions, always wrap buttons in h3 headings, synchronize sibling aria-expanded states on close, style with :focus-visible outlines, and target both i and svg elements for state changes.
